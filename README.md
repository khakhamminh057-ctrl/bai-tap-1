# Quản lý thông tin sản phẩm (HTML & CSS)

Giao diện quản lý thông tin sản phẩm được thiết kế theo yêu cầu bài tập thực hành.

## Cấu trúc thư mục
- `index.html`: Tệp giao diện chính chứa cấu trúc form.
- `style.css`: Tệp định dạng CSS (bo góc, màu nền, hiệu ứng hover, focus cho input, nút bấm).

## Cách chạy dự án
1. Tải toàn bộ mã nguồn hoặc giải nén tệp zip.
2. Mở tệp `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...) để xem kết quả.
